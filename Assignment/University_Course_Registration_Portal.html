    Developer notes — a bug found with console.log() and fixed
    While wiring up calculateSelection(), the running credit total came out as "03414" instead of 15. Adding console.log(typeof course.credits, course.credits) inside the loop showed each value was still a string read from a DOM data-* attribute, so total += credits was concatenating text instead of adding numbers. The fix was to coerce it explicitly with Number(course.credits) before accumulating. The corrected function is what runs on this page; open DevTools Console and submit the form to see its debug output.
