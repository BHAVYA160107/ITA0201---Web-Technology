Key Points to Note

  • URL: full address of the resource being fetched.
  • Protocol: whether the resource was fetched over http or https.
  • Method: almost all these are GET requests.
  • Status Code: 200 = success, 304 = cached, 404 = not found.
  • Type: document, stylesheet, script, image, xhr/fetch, font.
  • Size: transferred vs actual size (note if "from cache").
  • Time: how long each request took.

Conclusion

Loading a single web page triggers multiple separate HTTP/HTTPS requests — for the HTML document, external CSS, image, and API resources — each with its own protocol, method, and response status, all visible in the Network tab.
